# C4 技能提交自动评审器

## 输入
- 一个本地文件夹路径，内含按 `姓名_C4_内容.扩展名` 命名的 C4 提交文件。

## 输出
- `评审报告.md`：班级总览、排名、逐作者完整性 + 质量评审 + 改进建议。
- `评审详表.csv`：结构化数据，便于汇总与二次统计。

## 用法
```bash
python skill_evaluator.py <文件夹路径> --out ./reports
```

## 评审逻辑
1. **文件采集**：递归扫描文件夹，跳过隐藏目录/文件。
2. **作者识别**：文件名前缀（`_C4_` 之前）→ 父目录名 → `Unknown`。
3. **完整性检查**：贪心匹配 5 类必交文件（说明 / 可执行内容 / demo / 教学说明 / AI 日志）。
4. **质量评审**：可复用、可执行、可验证、IO 明确四条件，按正向/负向信号打分。
5. **综合分** = 完整性 × 0.4 + 质量 × 0.6。

## 扩展点
- 规则库在 `references/c4_rubric.json`：改信号、加维度、调阈值都无需改代码。
- 预留 LLM 深审钩子：后续可在质量评审处接入 OpenAI 兼容接口（含本地 ollama）做语义级深审，与规则快筛形成「规则为主、LLM 可插拔」的混合架构。

## 环境要求
- Python 3.8+，纯标准库（os/re/json/csv/zipfile/argparse），无需 pip 安装任何第三方包。
- 跨平台：Windows / macOS / Linux 均可运行。
